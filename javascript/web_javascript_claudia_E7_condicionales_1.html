Ejercicio 07 — Introducción de datos y toma de decisiones

En este ejercicio se trabaja con preguntas al usuario y estructuras condicionales para tomar decisiones según la respuesta.Este programa pregunta al usuario si quiere jugar. Si dice que sí, le pide una fruta y muestra su precio. Después hace otra pregunta y responde según lo que escriba. También avisa si se introduce una respuesta incorrecta.
