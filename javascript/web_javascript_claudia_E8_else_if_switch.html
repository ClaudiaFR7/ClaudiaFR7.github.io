Ejercicio 08 — else if y switch

En este ejercicio uso if, else if y switch para tomar decisiones en JavaScript. También he corregido errores y probado los programas.

Explicación

Ejercicio 1: Pide un número y dice si es positivo, negativo o cero.

Ejercicio 2: Pide una contraseña y comprueba si es correcta.

Ejercicio 3: La variable es null y el programa lo detecta.

Ejercicio 4: Comprueba si un número es positivo y si es par o impar.
